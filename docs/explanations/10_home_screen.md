# 10 — الشاشة الرئيسية (03 و28) وأدوات التطوير

**الملفات:** `lib/features/home/home_screen.dart` · `widgets/*.dart` · `dev_tools_sheet.dart` · `lib/features/catalog/subject_visuals.dart` · **Figma:** `03 الرئيسية` (3:283)، `28 الرئيسية — أول يوم` (21:663)

## الغرض
شاشة واحدة تتبدّل بحسب `HomeState` (انظر `09_home_state.md`):

| العنصر | أول يوم (28) | بعد النشاط (03) |
|---|---|---|
| الشريط العلوي (جديد) | الشعار مع التميمة + «دون إنترنت» + زر الحساب | نفسه |
| التحية | «أهلًا، {الاسم}» + «يومك الأول في رِزمة. لنبدأ معًا!» | «مرحبًا، {الاسم}» + «جاهز لدرس اليوم؟» (كانت «ماذا تريد أن تتعلم اليوم؟») |
| بلاطتا النجوم والسلسلة | غير ظاهرتين | النجوم دائمًا، والسلسلة إن كانت > 0. في الطابع الهادئ (7–12) تصيران سطرًا في التحية |
| البطاقة الخضراء | «ابدأ أول درس: {عنوان}» + المدة + زر «ابدأ الدرس» | «الدرس N: {عنوان}» + شريط التقدّم + «تابع الدرس» (كانت «متابعة التعلم») |
| خطواتك الأولى | تظهر (X من 3) | لا تظهر |
| المراجعة | صندوق منقّط يشرح متى تظهر | قسم «يحتاج إلى مراجعة» بعد أول اختبار فقط |
| موادي | شبكة «لم تبدأ» | النسبة لما بُدئ (شبكة للصفوف 1–6، قائمة بأشرطة للصفوف 7–12) |

> **تحديث التصميم الجديد:** الترتيب والمنطق كما هما، تغيّر الشكل فقط: شريط علوي، تميمة كبيرة بجانب التحية (للصغار)، بلاطات ملوّنة، بطاقات بحافة سفلية، صفوف مراجعة مرجانية، ومواد بشبكة أو قائمة حسب العمر.

## `HomeScreen` (`ConsumerWidget`)
- يقرأ `homeStateProvider` ويستعمل `AsyncValue.when`: `loading` ← فراغ، `error` ← «تعذّر تحميل الرئيسية.»، `data(null)` ← فراغ.
- `bottomNavigationBar`: `BottomNav` بالتبويب «الرئيسية». باقي التبويبات بلا وظيفة بعد (شاشاتها خارج النطاق الحالي).
- أزرار الدرس و«عرض الكل» والمراجعة وبطاقات المواد كلها تعرض `SnackBar` صادقًا: «مشغّل الدروس قيد الإعداد وسيتوفّر قريبًا.» لأن المشغّل غير مبني.
- `_HomeBody`: `SingleChildScrollView ← Column(spacing: 14)` يضيف كل قسم بشرطه (`if (state.hasActivity)`، `if (state.isFirstDay)`…).

### أيقونات وألوان المواد
الكتالوج يحدّد `icon` (مثل `calc`) و`color` (مثل `teal`) لكل مادة. `subject_visuals.dart` يحوّل مفتاح الأيقونة إلى ملف SVG، وألوان المادة تأتي من `ProfileColorPalette` (`body` للتمييز و`avatarBackground` لخلفية المربع). هكذا تُضاف مادة جديدة من JSON فقط.

## أدوات التطوير (`dev_tools_sheet.dart`) — debug فقط
تُفتح بضغطة مطوّلة على الأفاتار **فقط حين `kDebugMode`** (في release لا يُمرَّر معالج الضغط أصلًا، فيُحذف الكود). الغرض: إدخال نشاط تجريبي لنتأكد أن الرئيسية تنتقل من 28 إلى 03، ريثما تُبنى شاشات الدروس.

| الإجراء | ما يكتبه في القاعدة |
|---|---|
| تحميل الدرس التالي | `lesson_progress`: `downloaded` |
| بدء الدرس التالي (50%) | `inProgress` بنسبة 0.5 |
| إكمال الدرس التالي | `completed` بنسبة 1 |
| تدريب (+3 نجوم) | `attempts`: `practice` بـ 3 نجوم |
| اختبار ضعيف | `attempts`: `quiz` بنجمة، و`concept_mastery` لأول مفاهيم الدرس 0.4 والباقي 0.9 |
| مسح نشاط هذا الملف | `ActivityDao.clearActivity` |
| تبديل الطالب | ينتقل إلى `/profiles` |

«الدرس التالي» = أول درس غير مكتمل بترتيب الكتالوج. النصوص عربية لكنها لا تظهر للطلاب في release.
