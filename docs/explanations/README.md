## ملفات PDF
- **شرح بحسب الموضوع:** `pdf/` — نسخة PDF من ملفات `.md` هذه.
- **شرح سطرًا بسطر لكل كود `lib/`:** `docs/line_by_line/` — 31 ملفًا (الأساس، قاعدة البيانات، منطق الملفات، المكوّنات المشتركة، الكتالوج، ثم كل شاشة، وبعد الـ16: المحتوى، محرّك الجولة، أجزاء الدرس، التصفّح، ودجتات الأسئلة، شاشات الجولة، تقدّمي والتنزيلات، الخزانة، رئيسيات الصفوف، الودجتات الأساسية الجديدة، المسارات والنصوص، ثم **31: نظام التصميم الجديد**). كل مقطع كود يتبعه «ماذا يفعل؟» و«لماذا بهذه الطريقة؟»، والتغطية كاملة: كل سطر غير فارغ في كل ملف `.dart` (غير المولَّد) مشروح.
- **قديمة:** `docs/01_welcome_screen.pdf` و`02_grade_selection_screen.pdf` و`03_home_screen.pdf` شرح سطري **للنسخة الأولى** من الشاشات الثلاث (قبل قاعدة البيانات والراوتر). حلّت محلّها ملفات `docs/line_by_line/`.

## ما لم يُبنَ بعد
مشغّل الفيديو الحقيقي (ملفات الفيديو غير مضمّنة)، الوضع الليلي (الثيم الداكن) وربط مفاتيح التخزين والأصوات بميزاتها، المزامنة، تنزيل الحزم من خادم، كتالوجات الصفوف غير الخامس، ومراجعة المحتوى من معلم.
